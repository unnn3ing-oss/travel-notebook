# 旅行手帳

排行程、存備案，旅途中只看現在和下一站。資料只存在這支手機（IndexedDB），不需要帳號，也不需要網路。

## 目前有的功能（v0.1）

- **總覽**：出發倒數、出發前準備的期限（例如「要在 11/08 前完成（還剩 3 天）」）、預訂狀態
- **今日**：現在、下一站、稍後；依目前時間提醒幾點要出發去搭車
- **行程**：依日期排卡片，可以新增、編輯、刪除；時間重疊時會提醒，並能把後面的行程一起延後
- **交通班次**：每條路線存班次，依目前時間判斷每一班還來不來得及
- **改用備案**：主方案不行時換成備案，可以復原
- **準備清單**：期限從出發日往前算，改出發日會自動更新

預訂狀態只有三種：**還沒訂**、**已訂購**（付款了，還沒收到確認信）、**訂單確認**（收到確認信了）。

第一次開啟會放入「京都 5 日」範例資料。

## 模擬旅途中的時間

網址加上 `?now=`，就能看到某個時間點的畫面，例如：

```
/?now=2026-11-21T13:44
```

## 開發

```bash
npm install
npm run dev     # 本機開發
npm test        # 單元測試
npm run build   # 型別檢查＋建置到 dist/
```

技術：React 19、Vite 8、TypeScript、Dexie（IndexedDB）、vite-plugin-pwa。部署在 Vercel，push 到 `main` 會自動更新。
