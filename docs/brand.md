# 旅行手帳 品牌規範

## 圖示概念

**P3-S1 航線弧＋經典噴射機**：白色虛線航線繞將近一圈，黃色飛機在左上角把航線接起來，順著航線往右上飛。意思是「沿著排好的行程，一站接一站往前走」。

## 色彩

| 名稱 | Hex | 用途 |
|---|---|---|
| 深藍（主色） | `#1E2A44` | 圖示底色、文字、主要按鈕 |
| 黃（強調色） | `#F2C14E` | 飛機、即將開始的旅程、選中的分頁 |
| 紙白 | `#F4F6F9` | 航線、App 背景 |
| 輔助灰藍 | `#C9D1DE` | 深色底上的次要文字 |

比例大約是深藍 70%、紙白 20%、黃 10%。黃色只放在一個焦點上，不要大面積使用。

## 檔案（`public/`）

| 檔案 | 尺寸 | 用途 |
|---|---|---|
| `icon.svg` | 向量，圓角 22% | 網頁 favicon、一般展示 |
| `icon-square.svg` | 向量，滿版 | manifest、系統會自行裁圓角的地方 |
| `icon-maskable.svg`／`icon-maskable-512.png` | 圖形縮到 80% | Android 自適應圖示（安全區內） |
| `icon-1024.png` | 1024 | App Store、宣傳素材 |
| `icon-512.png`／`icon-192.png` | 512／192 | PWA manifest |
| `apple-touch-icon.png` | 180 | iOS 加到主畫面 |
| `favicon.ico` | 16／32／48 | 舊瀏覽器 |
| `favicon-16.png`／`favicon-32.png` | 16／32 | 瀏覽器分頁 |
| `icon-mono-light.svg` | 向量，深藍單色、無底 | 淺色背景、印刷 |
| `icon-mono-dark.svg` | 向量，白色單色、無底 | 深色背景、照片上 |

## 使用規則

- **最小尺寸**：彩色版 16px；單色版 20px（更小時虛線會連在一起）。
- **最小留白**：四周至少留圖示寬度的 12.5%（100 單位的 viewBox 裡就是 12.5）。
- **不要做的事**：改顏色、加陰影或漸層、旋轉飛機、拉長變形、把虛線改成實線、在花俏背景上直接放彩色版（請改用單色版）。

## 字型搭配

| 用途 | 字型 |
|---|---|
| 中文、內文 | Noto Sans TC（400／500／700） |
| 數字、時間、金額 | Space Grotesk（500／700），一律 `font-variant-numeric: tabular-nums` |

## 重新產生

執行 `node scripts/build-icons.cjs` 會重新輸出 `public/` 裡所有圖示（`favicon.ico` 另外用 Pillow 從 `icon-512.png` 轉出）。

圖示是從同一份幾何定義產生的：航線圓心 (51, 53)、半徑 28，從 −30° 畫到 200°，虛線 `8 13`，線寬 7；飛機放在 236° 的位置，順著切線方向。要調整時改定義，再重新輸出所有尺寸，不要個別修改 PNG。
